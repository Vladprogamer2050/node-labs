## Состав репозитория

| Папка | Лабораторная работа |
|---|---|
| `lab-11-setup` | Установка и настройка Node.js и NPM, Git, ветка, Pull Request |
| `lab-14-fs` | Работа с файловой системой (`fs`) |
| `lab-15-koa` | Простой сервер на Koa.js |
| `lab-16-express` | Простой сервер на Express.js |
| `lab-17-cli` | CLI-приложения |
| `lab-18-os` | Модуль `os` |
| `lab-19-events` | Модуль `events` |
| `lab-20-http` | Управление маршрутами (HTTP Request) |
| `lab-21-streams` | Потоки в Node.js |
| `lab-22-mysql` | Подключение к MySQL |
| `lab-23-mongo` | Работа с MongoDB |
| `lab-24-rest-api` | REST API (Koa + MongoDB) |

## Запуск первой работы

```bash
npm start
```

Сервер поднимается на http://localhost:3000 и отдаёт страницу «Привет, мир!».
